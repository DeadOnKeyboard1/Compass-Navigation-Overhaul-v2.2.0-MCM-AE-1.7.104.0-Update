- Removed misleading VR/all build presets from this 1.7.104 SE/AE-only source tree.
- Corrected documented CMake configure/build commands.
- Updated dependency/license provenance documentation.

## CTD hardening pass v3

- Removed unsafe `GFxValue -> GFxMovieView` reinterpret-cast helpers. CNO UI wrappers now carry the live HUD `GFxMovieView*` explicitly.
- Added HUD lifecycle invalidation/rebinding around InfinityUI `StartLoadInstances`, post-patch, abort and finish notifications.
- `Compass`, `QuestItemList` and the debug `Test` object no longer retain usable-looking Scaleform handles across HUD teardown.
- Added type/readiness checks before constructing ActionScript arrays/objects or calling `localToGlobal`.
- CoMAP/MapMarkerFramework movie-definition hook now falls back to the original movie's definition while CNO's patched definition is unavailable; the hook ABI preserves the movie pointer in RDX.
- Hardened the compatibility signature scanner to inspect only committed readable pages and to stop safely on `VirtualQuery`/module-info failures.
- Removed the custom `INISettingCollection`/`Setting` VTable/layout replicas. Settings are read directly from the plugin/MCM INI files, eliminating an engine ABI dependency.
- Removed the local duplicated Scaleform `RE/G/*` implementation and `source/RE/G/GFxValue.cpp`; CNO now uses CommonLibSSE-NG 7.5.4's Scaleform types/relocations directly.
- Removed unused duplicate global `utils/GFx*` wrappers.
- Reduced the private `RE::HUDMarkerManager` mirror to an opaque singleton plus the small marker data structures CNO actually needs.
- Removed direct reads/writes of `HUDMarkerManager::currentMarkerIndex`, `sqRadiusToAddLocation` and `scaleformMarkerData[]`.
- Marker indices are derived from the engine-provided `ScaleformData*` only after strict alignment/range validation; if validation fails, vanilla marker handling continues and CNO skips only optional metadata processing.
- Unknown-location icon replacement writes through the already supplied marker-data pointer instead of indexing a mirrored engine array.
- Location hook no longer duplicates the engine's private radius check; the hook runs at the original `AddMarker` call site after vanilla gating has already succeeded.
- Hook validation now verifies readable committed memory before reading candidate CALL instructions.
- NPC Names Distributor API lookup now checks the DLL module handle before `GetProcAddress`.
- Normalized the local precompiled-header include case (`pch.h`).

## v3.3 build-compatibility fix

- Fixed an MSVC/Windows SDK preprocessor collision in `include/utils/Trampoline.h`: the Windows `MEM_RELEASE` macro expanded inside `REX::W32::MEM_RELEASE`, producing the C2589/C3878 syntax errors seen in `CNO-build-20260923-171821.log`.
- `VirtualFree` now uses the documented numeric `MEM_RELEASE` flag (`0x00008000u`) at the call site, avoiding namespace-qualified macro expansion while preserving identical Win32 behavior.
- Re-scanned the project for other namespace-qualified Win32 constant names that can be replaced by Windows SDK macros; no additional occurrences remain.


## v3.4 build packaging fix

- Fixed DLL/PDB discovery in `Build-CNO-1.7.104.bat`. `FOR /R` with a literal filename could leave a non-existent candidate path even though the linker produced the DLL successfully.
- Output discovery now uses `dir /b /s /a-d`, which only returns files that actually exist.
- Every DLL copy is checked; the batch can no longer print `BUILD SUCCESSFUL` unless `dist\SKSE\Plugins\CompassNavigationOverhaul.dll` really exists.
- The DLL is also copied to `dist\CompassNavigationOverhaul.dll` for easier manual access.
- PDB is likewise copied to the `dist` root when available.

## v3.6 marker restoration

- Fixed a regression where the location/enemy/player hook wrappers could return before Skyrim's original `HUDMarkerManager::AddMarker` call when auxiliary pointers were unavailable. Because those wrappers replace the original call, that suppressed the marker itself.
- Non-quest hooks now preserve vanilla marker creation first and treat CNO metadata processing as best-effort.
- Removed the duplicate CNO-side `sqRadiusToAddLocation` check from the location hook. Skyrim has already passed its own UpdateLocations gating before execution reaches the replaced AddMarker call; mirroring a private layout field could incorrectly suppress every location marker.
- The user-facing option that hides undiscovered location markers remains intact when valid map-marker data is available.
